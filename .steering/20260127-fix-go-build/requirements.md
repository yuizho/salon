# Requirements

## 概要
GitHub ActionsでのGoビルドエラーを修正する。
エラーログによると、`go.mod`で指定されたバージョン（`1.24.0`）とCI環境のGoバージョン（`1.18`）の不整合が原因であるため、これを解消する。

## 現状の問題
- CI（GitHub Actions）のGoバージョンが `1.18` に固定されている。
- `backend/lambda/room-rmu/go.mod`（おそらくpushされたもの）が `1.24.0` を指定している。
- 古いGoツールチェーン（1.18）が新しいバージョン形式や `toolchain` ディレクティブを認識できずエラーとなっている。

## 対応内容
1.  **CI環境の更新**: `.github/workflows/build_backend.yml` のGoバージョンを `1.24` に更新する。
2.  **go.modの整合性確認**: ローカルの `go.mod` ファイルも `1.24` (または `1.24.0`) に更新し、整合性を保つ。

## 完了条件
- GitHub Actionsのビルドが成功すること。
- ローカルでのビルド/テストが成功すること。
