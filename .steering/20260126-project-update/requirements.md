# Project Update Requirements

## Overview
Update project dependencies, languages, and frameworks to their latest stable versions to ensure security, performance, and maintainability.

## Targets
- **Backend (Go)**: Update Go to 1.21+ and AWS SDKs.
- **Backend (CDK)**: Update CDK to latest v2 and dependencies.
- **Frontend**: Update Next.js (v12 -> Latest), React, AWS Amplify, and Storybook.
- **Tooling**: Update ESLint, Prettier, and Husky.

## Constraints
- Ensure functionality remains intact.
- Verify through existing tests and builds.
